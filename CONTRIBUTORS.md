# Contributors

Playing MERGEFORGE is for contributors: people with at least one merged pull request in this repository (D-018). Everyone listed here got in that way, or was invited by the maintainer.

## Your first pull request in two minutes

You do not need Git on your computer.

1. Sign in to GitHub and open [`CONTRIBUTORS.md`](https://github.com/QuickLinkNet/mergeforge/blob/main/CONTRIBUTORS.md).
2. Click the pencil icon ("Edit this file"). GitHub offers to create a fork for you.
3. Add one line to the list below: `- your-github-name`
4. Click "Commit changes", then "Propose changes" and "Create pull request". Target branch: `dev`.
5. The maintainer merges it once the automatic checks are green.
6. Open <https://mergeforge.red-it.org> and sign in again. The game opens.

The first automatic check run on a pull request from a new contributor needs the maintainer's approval, so it can take a little while.

Prefer not to open a pull request? Use "Beitritt anfragen" on the sign-in page; the maintainer decides there.
